# PaysPOS – Mobile Point-of-Sale Application

PaysPOS is a **cloud-based Point of Sale (POS) mobile application** built with **React Native** and **Android Native**.  
It streamlines day-to-day operations for retail and hospitality businesses, enabling seamless sales, inventory, and customer management in one place.

---

## 🚀 Key Features

### 🕒 Employee Management
- Clock-In / Clock-Out tracking  
- Shift & attendance monitoring

### 📦 Inventory Management
- Real-time stock updates  
- Low-stock alerts and detailed reporting

### 👥 Customer Management
- Customer profiles and purchase history  
- Built-in loyalty program and gift card support

### 💳 Payment Gateway Integrations
Supports multiple secure gateways:
- **PAX**, **Dejavoo**, **Magensa**, **Stripe**, **PaperPay**  

### 🛍️ Order Types
- Take-Out
- Open / Scheduled Orders
- Dine-In Orders
- Phone Orders

### ✨ Advanced / Hardware Features
- **Printer & Hardware Integration**: Epson & Sunmi printers for barcodes, kitchen & customer receipts
- Split-Payment functionality with tipping
- U.S. Taxation integration & automated service charge
- Customer loyalty points management
- Gift card purchase & redemption
- Printer queue logic for high-volume kitchens
- Secure refund processing

---

## 🛠️ Tech Stack
- **Frontend:** Android Native  
- **Native Modules:** Android (Java/Kotlin) for printer/payment hardware integrations  
- **Backend & APIs:** (configure as per deployment)  
- **Payment Gateways:** PAX, Dejavoo, Magensa, Stripe, PaperPay
